# ADR-0002:路线 A —— 渐进式原生重构(零构建 / 无框架)

- 状态:已接受(2026-08-23,阶段 0)
- 关联:ADR-0001

## 背景

现状为 5 个纯静态 HTML(admin 120KB / creator 57KB / owner 43KB / index 39KB)+ 原生 JS + Vercel Serverless 函数,无构建链、无类型、无统一请求校验。全面重构需保留全部业务功能(订阅/支付/管理后台/同步/集成)。

## 决策

采用**路线 A:渐进式原生重构**,保持零构建、无框架:

1. **模块化模板**:拆分大 HTML 为可复用的页面骨架与区块模板,统一 head/导航/页脚/安全头;
2. **统一页面运行时**:共享 `store`(状态管理)、组件化渲染、统一事件委托;
3. **类型安全的 JS 校验层**:引入轻量 schema 校验(手写校验器,不引入依赖),统一请求/响应契约;
4. **统一 API 错误契约**:所有 Serverless 函数输出一致的错误结构(`{ ok, error: { code, message } }`)与状态码;
5. **node:test 全量覆盖**:扩展现有 26 项安全测试,按模块补齐单元/行为测试。

## 明确不做(本轮)

- 不引入打包器、框架、TypeScript 编译链;
- 不改变 Vercel 函数部署模型;
- 不迁移数据层(数据层演进另立 ADR)。

## 后果

- 正面:风险最低、每步可部署、无迁移期;
- 代价:长期维护仍靠纪律(校验层与组件规范兜底);
- 里程碑:先重构 index 页与公共 catalog 链路作为样板,再推 admin/owner/creator。
